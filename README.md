## 📖 About

QuickLook is a lightweight file preview utility for Windows that adds a macOS-style Quick Look behavior to Explorer. It is developed as an open project and packaged for Windows 10 and Windows 11, so once installed it sits quietly in the background and waits for a spacebar press. The 2026 edition improves image decoding speed, adds broader archive and document preview support, and refines HiDPI rendering on high resolution monitors.

If you came looking for a QuickLook download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes.

**Good for:** everyday Windows users · developers browsing source trees · photographers reviewing exports · students organizing coursework · IT staff inspecting shared folders · anyone who wants faster file browsing

## 🔑 Features

| Feature | Description |
| --- | --- |
| 👁️ **Spacebar preview** | Select a file in Explorer and tap space to open a preview popup instantly |
| 🖼️ **Image and photo viewer** | Renders PNG, JPG, GIF, BMP, WEBP, SVG, RAW and many other formats at full resolution |
| 📄 **Document reading** | Displays PDF, DOCX, XLSX, PPTX, Markdown and plain text without launching an editor |
| 🎬 **Video and audio peek** | Plays common video and audio containers in a compact player with basic controls |

## 🛠️ Troubleshooting

| Problem | Solution |
| --- | --- |
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway** |
| Spacebar does not open a preview | Check that QuickLook is running in the system tray and that preview is enabled |
| Preview window flickers or renders black | Update your graphics driver and restart Explorer from Task Manager |
| Some file types show a blank preview | Install the matching plugin from the tray plugin manager |
| App starts slowly on first launch | First run indexes shell handlers, subsequent launches are faster |
| Preview stays open after switching windows | Press Escape or click outside the popup to close it |
| Explorer feels unresponsive after install | Disable unnecessary plugins and restart the QuickLook background process |
